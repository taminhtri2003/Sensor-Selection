# Agent Guidelines & Workflow Rules

This document specifies instructions for autonomous AI coding and research agents working in this repository.

---

## Core Rules

1. **No Data Leakage**:
   - Held-out test participants in outer LOSO folds must NEVER be used during model training, feature scaling/normalization, hyperparameter tuning, or SHAP channel ranking generation.

2. **No Data Fabrication**:
   - Experiments must run strictly on downloaded public datasets (GRABMyo v1.1.0 and NinaPro DB5).
   - Never fabricate, estimate, interpolate, or invent experimental metrics.

3. **Participant-Level Statistical Unit**:
   - All statistical significance tests, bootstrap confidence intervals, and non-inferiority decisions must be computed at the participant level ($N=43$), not window level.

4. **Automated Number Verification**:
   - All manuscript numbers, table values, figure contents, and LaTeX macros must originate directly from result files generated by scripts and verified via `scripts/16_verify_results.py`.
