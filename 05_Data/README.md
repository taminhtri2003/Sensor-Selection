# Data

- [Raw_GRABMyo](Raw_GRABMyo/): the three original recording sessions, exposed through folder shortcuts.
- [Data_cache_and_metadata](../data): raw downloads, processed signals, feature caches, participant splits and dataset manifests.
- [Dataset_documentation](Dataset_documentation/): official montage, gestures, participant information, license, checksums and recording index.
- [Other_downloaded_recordings](../DESTINATION): the separately downloaded recording collection previously stored as DESTINATION. Its presence does not mean it contributed to the final study.

Original data remain in their existing working locations. The source checksum and RECORDS files refer to those canonical dataset paths. Dataset-supplied utilities are grouped under `03_Code/Dataset_utilities/`.
