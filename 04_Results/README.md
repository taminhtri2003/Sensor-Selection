# Results

- [Publication_tables](Publication_tables/): numerical data accompanying the final article.
- [Complete_statistics](../manuscript_revision/20261014/tables): detailed statistical outputs used for the study.
- [Additional_experiments](../manuscript_revision/20261014/experiments): participant predictions, matched-resource comparisons, geometric curves and sensitivities.
- [Primary_participant_metrics](../artifacts/metrics): original participant-level model metrics.
- [Rankings](../artifacts/rankings): cross-fitted electrode rankings and attribution summaries.
- [All_analysis_outputs](../artifacts): the complete historical artifact tree, including earlier or exploratory tracks that are not all part of the final article.

The participant is the statistical unit. Current publication claims must follow the final article and its verified source graph; a file existing in the historical artifact tree does not make it a publication result.
