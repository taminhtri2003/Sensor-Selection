# Archive

Earlier manuscripts, publication packages, reports and working records are separated here through folder shortcuts. The current article is in `01_Publication/`.

- `Previous_publication_packages`, `Earlier_manuscript`, `Original_manuscript_source`: older publication versions.
- `Scientific_record_20261014`: complete verified scientific record and its original archive.
- `Publication_record_20261016`: original clean presentation and author materials.
- `Earlier_reports`, `Earlier_reproducibility`, `Earlier_audits`, `Run_records`: historical documentation and execution records.
- `Invalidated_outputs`: explicitly invalidated outputs, preserved as historical records.
- `Timing_scratch`, `Temporary_work`: prior working files.

Canonical paths remain intact. Nothing was deleted, and the frozen scientific/publication packages were not edited. `Earlier_manuscript_archive.lnk` and `Earlier_status.lnk` open the older root ZIP and status file. The root study report is accessible from Documentation through `Historical_study_report.lnk`.
